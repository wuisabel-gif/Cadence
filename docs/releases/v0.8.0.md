# Cadence v0.8.0

Released November 26, 2026. Scores are unchanged from v0.7.0; no detector rule
changed.

## Highlights

- **An eleventh voice: `margin`.** A reasoned-essay register. It states the
  thesis in the first paragraph and takes the conditions one at a time.
  Asides go in parentheses, not between em dashes, and footnotes show the work.

Try it in any supported agent:

```
Use Cadence to recast this draft in the margin voice.
```

## Agent installs

```bash
npx --package=cadence-deslop@0.8.0 cadence-install-skill --agent kimi
npx --package=cadence-deslop@0.8.0 cadence-install-codex
```

Replace `kimi` with `zcode`, `claude-code`, `opencode`, or `grok` as needed.
Reinstall to pick up the new voice.

## Desktop installers

| System | File |
| --- | --- |
| macOS (Apple silicon and Intel) | `.dmg` |
| Windows | `.msi` or `.exe` |
| Linux | `.deb`, `.rpm`, or `.AppImage` |

The builds are not code-signed yet. On a Mac, open System Settings → Privacy &
Security and choose **Open Anyway**. On Windows, choose **More info → Run
anyway**. The app itself is unchanged from v0.7.0.
