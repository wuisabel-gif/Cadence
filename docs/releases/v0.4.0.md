# Cadence v0.4.0

Released September 20, 2026. Extension-store submissions remain separate from
the npm package and GitHub release.

## Highlights

- Install Cadence as a Grok Build CLI skill at `~/.grok/skills/cadence`.
- Pack the detector for a Grok Bot `/workspace` folder, then save a private
  skill in the app. This is not a Grok Bot marketplace listing.
- Export a local xAI function-calling bridge with `npm run build:grok`.
- grok.com chat still cannot load local skill folders.

## Upgrade notes

Detector scoring is unchanged from v0.3.0. The new surfaces add hosts, not
rules. Manifests share version 0.4.0. The unrelated README Auto Update
marketplace entry keeps its own version.

Run npm installers from your project or another directory, not from inside the
Cadence source checkout.

## Grok Build

```bash
npx --package=cadence-deslop@0.4.0 cadence-install-skill --agent grok
```

Or from a checkout: `npm run install:grok`. Start a new `grok` session and use
`/cadence`. See the [Grok guide](../../integrations/grok/README.md).

## Grok Bot

From a checkout:

```bash
npm run grok-bot:pack
```

Copy the packed folder to `/workspace/Cadence` on the Bot computer, score a
file, then send `SAVE_SKILL.md`. See [Grok Bot](../../integrations/grok-bot/README.md).

## Other agent hosts

```bash
npx --package=cadence-deslop@0.4.0 cadence-install-skill --agent kimi
npx --package=cadence-deslop@0.4.0 cadence-install-codex
```

Replace `kimi` with `zcode`, `claude-code`, or `opencode` as needed.

## Validation before publishing

Run the [release checklist](../RELEASING.md) on the exact commit to be tagged.
The package smoke check installs from the actual npm tarball. It does not prove
Grok Build discovery or a live Grok Bot run.
