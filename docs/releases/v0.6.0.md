# Cadence v0.6.0

Released October 21, 2026. Scores are unchanged from v0.5.0; no detector rule
changed.

## Highlights

- **A desktop app** for macOS, Windows, and Linux. It opens the score page in a
  native window and works offline. Paste text, drop a `.txt`, `.md`, or `.html`
  file, or open one with Cmd/Ctrl+O. Download the installer for your system
  from this release.
- **Every score names its detector.** Results carry `detectorVersion`, so a
  saved score says which rules produced it.
- **Releases publish from a tag.** npm packages now come from GitHub Actions
  with provenance, through npm trusted publishing.

## Desktop installers

| System | File |
| --- | --- |
| macOS (Apple silicon and Intel) | `.dmg` |
| Windows | `.msi` or `.exe` |
| Linux | `.deb`, `.rpm`, or `.AppImage` |

The builds are not code-signed yet. On a Mac the first launch is blocked: open
System Settings → Privacy & Security and choose **Open Anyway**. On Windows,
choose **More info → Run anyway**.

## Agent installs

```bash
npx --package=cadence-deslop@0.6.0 cadence-install-skill --agent kimi
npx --package=cadence-deslop@0.6.0 cadence-install-codex
```

Replace `kimi` with `zcode`, `claude-code`, `opencode`, or `grok` as needed.
Run npm installers from your project, not from inside the Cadence checkout.

## Accuracy

Unchanged. On the 0.5.0 held-out set the detector catches 3 of 34 AI samples
and leaves 31 of 32 human samples clean. A new held-out set,
`benchmark/heldout-0.6.json`, is frozen and unscored until the next rule
change. See the [benchmark](../../benchmark/README.md).
