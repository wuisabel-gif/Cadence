# Cadence v0.5.0

Released October 16, 2026. Extension-store submissions remain separate from
the npm package and GitHub release.

## Highlights

- Scores change. The triad rule now fires only on exact three-item lists, and
  three- or four-sentence texts can lose points for flat rhythm.
- The benchmark grew to 122 regression samples, plus a 66-sample held-out set
  that was never used for tuning.
- On held-out text the detector catches 3 of 34 AI samples (8.8%) and leaves 31
  of 32 human samples clean (96.9%). The 0.4.0 detector caught none of them.
- Node 20 or newer is required.

## Upgrade notes

Scores from 0.4.0 and 0.5.0 are not comparable. Lists of four or more items
no longer add triad points, so some human prose scores lower. Short text with
uniform sentence lengths can now pick up to 15 points. If you store scores or
gate on a cutoff, pin the version:

```bash
npx --package=cadence-deslop@0.5.0 cadence-install-skill --agent kimi
npx --package=cadence-deslop@0.5.0 cadence-install-codex
```

Replace `kimi` with `zcode`, `claude-code`, `opencode`, or `grok` as needed.
Run npm installers from your project, not from inside the Cadence checkout.

## Accuracy, stated plainly

Recall stays low. The score flags prose that uses the common tells. It is not
an authorship test, and most AI text that avoids those tells grades A. Run
`node benchmark/bench.mjs --corpus benchmark/heldout.json` to reproduce the
held-out figures. See the [benchmark](../../benchmark/README.md).

## Validation before publishing

Run the [release checklist](../RELEASING.md) on the exact commit to be tagged.
The package smoke check installs from the actual npm tarball. It does not prove
discovery in a live agent session.
